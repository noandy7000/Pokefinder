INSTALLATION

If you haven't Installed Python yet: Do that here is a Tutorial:
If you don't have the following python Libraries installed:
-customtkinter
-pillow
import them. If you don't know how: Run this Command in PowerShell, CMD or Terminal
-
python -m pip install customtkinter pillow
-
To Start: Open the .pyc file
